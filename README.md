# Hacka-USP 2026 — Capim

Hackathon by Núcleo de Empreendedorismo da USP + CodeLab, hosted at Capim (Nov 7–8, 2026).
Capim: dental fintech that offers credit for dental treatments.
Theme: **accessibility**.

Key deadlines: code freeze **Nov 8, 15:45**; pitches **16:00**.

## Structure
- `context/` — source material: Capim context file, talk transcript, schedule
- `docs/` — problem statement, ideas, decisions; `docs/research/` for notes and references
- `design/` — wireframes, mockups, `assets/` (logos, images)
- `src/frontend/`, `src/backend/` — application code
- `data/` — sample/mock data
- `pitch/` — slides and pitch script
